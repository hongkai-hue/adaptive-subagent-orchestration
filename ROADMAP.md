# Roadmap

## Current stage

The `v0.1.0` open-source Release Candidate passed integration and independent QA. The
manual publication gate is approved, and public repository creation and verification are
in progress.

## Completed and verified

- L0-L3 routing, parent control, full-run file ownership, write-before-`BLOCKED`,
  structured results, evidence invalidation, transport boundaries, bounded retry, and
  no recursive delegation are represented in the English runtime contract.
- Seventeen forward fixtures cover routing, contract, and safety outcomes.
- Portable lifecycle tooling supports dry-run, user/repository/custom targets, explicit
  replacement, a checksum manifest, sibling backup, target locking, validation, and
  fail-closed uninstall.
- Bilingual public guidance, governance files, public cases, architecture, frozen v1
  contract, and a runtime surface matrix are present.
- Contract, lifecycle, architecture, documentation, link, and privacy tests run through
  recursive standard-library discovery.

## In progress

- Create the approved clean public history without attaching the internal repository.
- Run GitHub Actions and fresh-clone lifecycle verification against the public repository.

## Next

- Publish `v0.1.0` only after public CI and fresh-clone Gates pass.
- Record the public repository and Release evidence after online verification.
- Collect additional sanitized App/CLI evidence before expanding support claims.

## Known limitations

- Exact account, provider, model, and reasoning identity are `UNVERIFIED` without
  sanitized request-level evidence.
- CLI and complete App/macOS/Linux runtime coverage are not yet public v0.1 claims.
- Windows lifecycle support is out of scope for v0.1.
