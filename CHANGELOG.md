## [0.2.0] - 2026-08-05

- Bundled a self-contained `orchestrate-heavy-goals` companion Skill in the same repository, including architecture, diagram, artifact, node, QA, recovery, and L3 handoff references plus a safe Markdown scaffold.
- Added the frozen `l3-v1` ownership-transfer contract, schema-v1 L3 fixtures, a public end-to-end L3 case, and a closed-loop routing visual.
- Added manifest v2 capabilities and atomic `adaptive|heavy|all` install, replacement, validation, rollback, and logical uninstall behavior while preserving adaptive-only command compatibility and legacy v1 reads.
- Upgraded adaptive forward fixtures to schema v3 with explicit handoff state and expanded recursive tests for both runtime bundles, packet digests, exact installed trees, suite rollback, and cleanup debt.
- Added opt-in `compute-offload` mode with a fail-closed D1 single-worker route, sequential discovery, and optional read-only review while keeping `balanced` as the default.
- Previously upgraded forward fixtures to schema v2 with 25 routing and safety cases; v0.2 supersedes that fixture schema with v3 handoff metadata.
- Added a frozen compute-offload contract, architecture, public case, mode-aware AGENTS template, and explicit host-command boundary.
- Added bilingual public guidance, lifecycle safety notes, governance files, two routing cases, and a runtime surface matrix.
- Added explicit documentation for L0-L3 routing, owner and evidence boundaries, implicit-trigger limits, and provider/account neutrality.
